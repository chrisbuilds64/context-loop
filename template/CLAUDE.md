# Project Instructions

This project uses Context Loop. How it behaves is written in `context/rules.md`. Read that file
at the start of every session and follow it. `context/README.md` is the map: every file the loop
uses, what it holds, and what to edit to change the behaviour.

Start a session with `/session-start`. End it with `/session-end`.

build commands and working rules belong in `context/rules.md`, under "Your own rules", where
every environment reads them.>
