# Session logs

One file per session, written by `/session-end`.

Naming: `YYYY-MM-DD_topic-slug.md`. The date leads so the age of a file is visible in its name.

The way into this folder is `../session-index.md`: one line per log, with its topics and
keywords. Search there, then open the log the line points to.

An annotated example of what a good one looks like is `example-session-log.md`: it comes with
the file packages of Context Loop and is in its repository under `template/`. It is kept out of
this folder on purpose: a log in here is history, and a made-up history is worse than none.
