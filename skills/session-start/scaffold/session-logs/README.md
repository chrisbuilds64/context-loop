# Session logs

One file per session, written by `/session-end`. Nothing here yet — the first one appears when
you close your first session.

Naming: `YYYY-MM-DD_topic-slug.md`. The date leads so the age of a file is visible in its name.

An annotated example of what a good one looks like is in `example-session-log.md` at the root of
this project. It is kept out of this folder on purpose: a log in here is history, and a made-up
history is worse than none.
