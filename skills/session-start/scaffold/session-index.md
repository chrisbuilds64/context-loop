# Session index

One line per session, oldest at the top. `/session-end` adds the line, `/session-start` adds any
that are missing. Each line is a copy of the head of its session log: when the two differ, the
log is right and the line is rebuilt.

To find something, search this file for a topic or a keyword and open the log the line points to.

```
<YYYY-MM-DD HH:MM> | <topics> | <log file> | <summary> | keys: <keywords>
```
