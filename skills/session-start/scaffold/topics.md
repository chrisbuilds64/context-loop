# Topics

The topics of this project. One short name each: lowercase, hyphens, and it does not change once
it is in use. Session logs, the index, decisions and the project state carry this name.

"Also called" holds the other words the same topic has been named. When you use one of them, the
agent takes the topic's name and says so. Two names that turn out to be one topic are joined by
moving one into "Also called" of the other; no log is edited.
