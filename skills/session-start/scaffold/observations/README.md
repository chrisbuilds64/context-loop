# Observations

One file per thing the work taught you, dated in the filename so the age is visible without
opening it:

```
2026-01-15_agent-rebuilt-after-new-information.md
2026-01-22_documented-path-was-never-tried.md
```

`/observe` writes them, mid-session, when you notice something — not at the end, when the detail
has already gone. Each one says what happened, what it implies about the system, and where it
goes next: into `decisions.md`, into the agent's `working-notes.md`, or on hold until a pattern
forms behind it.

**This directory is meant to stay small.** `/observe` refuses things that are a bug with a fix
rather than a pattern, and that refusal is the point. Forty files nobody reads are worth less
than four that changed something.
